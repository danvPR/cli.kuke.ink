    02写法
    
      
    接近 JavaScript，
    AI 不用学新语法
    
      
    自研的积木文本语法。变量、循环、分支、模板字符串、对象与列表，都是 AI 最熟悉的写法；其余积木统一写成 category.block(…)。
    
    
    
    
    
      
    
        
    data-structures · 示例程序
    
        
    
      
    
      
    写法像 JavaScript，但只描述积木，从不被执行；部分积木为 Gandi 专有。对象与列表需先安装「高级数据结构」扩展。
    
    
    
    
      
      
    • 分支if (…) { } else if (…) { }
      • 
      
    • 循环for (let i = 1; i <= 5; i++)
      • 
      
    • 变量score += 1;
      • 
      
    • 模板`第 ${i} 个`
      • 
      
    • 对象player.hp += 10;
      • 
      
    • 列表log.push(i * 2);
      • 
    
    
    
    
      
    
        0.1.1 · 块式
        
    
      
    
      
    →
    
      
    
        0.2.0 · JS 风格
        
    
      
    
    
    
  
    

    



    
  
    
    
    
      
    03能力
    
      
    AI 需要的，
    都在命令行里
    
    
    
    
    

      
    
        
    多场景
    
        
    
        
    带参数切换场景。命令行用 gandi scenes 管理，gandi run --scene 指定场景。示例程序。
    
      
    

      
    
        
    角色与分组
    
        
    
          
    ▾战斗
    
          
    Player
    
          
    Bullet
    
          
    ▾敌人
    
          
    Enemy
    
          
    Director
    
        
    
        
    名字里写 战斗//Player，角色就进文件夹。
    
      
    

      
    
        
    测试与断言
    
        
    $ gandi assert --json '{"checks":[
  "score >= 3",
  "Hero.x > 0"
]}'
$ gandi test REF --expected-rev REV --strict-exit
    
        
    • score >= 3
    • Hero.x > 0
    
        
    断言、保存在作品里的测试套件、逐帧输入。勾选为示意；有 setup 的用例属于受控状态，会如实标出。
    
      
    

      
    
        
    智能排布
    
        
    
          
    
          
    
          
    
          原版「整理积木」新排布
        
    
        
    gandi arrange：按逻辑分组、分列、按尺寸装箱，整次排布是编辑器里的一步撤销。
    
      
    

      
    
        
    
          
    Ctrl + V，
    文本直接变积木
    
          
    编辑器内：剪贴板里是 DSL，在工作区按 Ctrl V：积木落在鼠标处、不压住已有脚本、新脚本自动选中，整次粘贴是一步撤销。编译失败则一块都不插，并提示第一条诊断。
    
          
    右侧为编辑器真实截图，拖动对比。
    
        
    
        
    
          
    
          
    
          
    
          粘贴前粘贴后
        
    
      
    

      
    
        
    
          
    对象 · 列表 · 集合
    
          
    
          
    对象字面量、属性自增、列表 push，直接对应「高级数据结构」扩展的积木。需先安装该扩展。示例程序。
    
        
    
        
    
      
    

      
    
        
    扩展自动安装
    
        
    
        
    读到没装的扩展，先按写入同样的确认与权限安装。扩展会运行第三方代码。
    
      
    

      
    
        
    版本保护
    
        
    $ gandi write REF --file draft.js \
    --base-rev REV
E_CONFLICT
    
        
    每次写入带修订号。冲突被拒绝，而不是悄悄覆盖。
    
      
    

    
    
  
    

    



    
  
    
    
    
      
    
        
    04流程
    
        
    六步，
    一个闭环
    
        
      
          
    1. start
    2. read
    3. check
      4. 
          
    4. write
    5. run
    6. verify
      7. 
        
    
      
    
    
    
    
    
      
    

      
    
        
    01
    
        
    
          
    start
    
          
    启动本机后台服务，在编辑器里点一次「连接 CLI」，你在本机授权页确认。
    
          
    真实输出 · 服务未启动时
    

    $ gandi doctor
{"bridge":false,"paired":false,"bound":false,"next":"gandi start"}
$ gandi start
# 连上编辑器后：gandi editors · gandi use EDITOR_ID · gandi bind
    
        
    
      
    

      
    
        
    02
    
        
    
          
    read
    
          
    编辑器是一棵虚拟源码树。先看概况，再读具体页面，读回来的内容带修订号。
    
          
    来自 gandi --help
    

    $ gandi overview
$ gandi files --kind blocks
$ gandi read REF --offset 1 --limit 100
$ gandi grep 'score' --glob '**/*.js' --context 2
# 输出连上编辑器后才有 · 示意
    
        
    
      
    

      
    
        
    03
    
        
    
          
    check
    
          
    只检查不写入。报错带行、列和改法。
    
          
    诊断条目为真实编译器输出 · 外层为示意
    

    $ gandi check REF --file draft.js
{"code":"E_UNKNOWN_VAR","message":"Unknown identifier zzz; declare it first",
 "line":2,"column":3,"severity":"error",
 "fix":"const zzz = sprite.variable(\"zzz\", 0);"}
    
        
    
      
    

      
    
        
    04
    
        
    
          
    write
    
          
    带着读到的修订号写入。也可以先 --dry-run 预览精确替换的差异。
    
          
    来自 gandi --help
    

    $ gandi write REF --file draft.js --base-rev REV
$ gandi edit REF --edits-file edits.json --base-rev REV --dry-run
# 修订号过期 → E_CONFLICT，不会覆盖
    
        
    
      
    

      
    
        
    05
    
        
    
          
    run
    
          
    在后台运行器里逐帧运行，注入键盘与鼠标，不碰你正在编辑的作品。
    
          
    入参来自 guide testing · 输出为示意
    

    $ gandi run --json '{"frames":60,"inputs":[
    {"frame":2,"key":"space","down":true},
    {"frame":12,"key":"space","down":false}]}'
$ gandi state · gandi logs · gandi view --output stage.png
    
        
    
      
    

      
    
        
    06
    
        
    
          
    verify
    
          
    断言通过才算数。保存成测试套件，每个用例从同一份快照、在全新的运行时里开始。
    
          
    来自 gandi --help · 输出为示意
    

    $ gandi assert --json '{"checks":["score >= 3","Hero.x > 0"]}'
$ gandi test REF --expected-rev REV --strict-exit
$ gandi export --output NEW.sb3
    
        
    
      
    
      
    终端内容为示意，实际输出以你的作品为准。
